Try autofill

Practice forms for everything the Jace Passwords extension fills. Nothing you enter here is sent anywhere: the forms only pretend to submit. Fields turn green when they're filled. Save a login with the website https://jace-passwords.vercel.app to see it offered here.

Sign in not filled

Click Email and pick a login. The password fills too. Press Sign in, and if it's a new or changed login you're offered to save it.

Sign up not filled

Click New password and choose "Use a strong password": both password boxes get it. Press Create account to be offered to save it.

2FA code not filled

The code menu opens by itself. Pick "Fill 2FA code" right after filling a login that has a 2FA code, or pick the login.

Code in boxes not filled

Six one-digit boxes, like many banks use: the code is spread across them.

Emailed code not filled

Send yourself an email that says "Your verification code is 482913", keep Gmail, Outlook or Proton Mail open (or turn it on under ✉ Email codes in the toolbar button), then click this field.

Passkeys not tried

Create a passkey for this page (Jace Passwords asks to save it), then sign in with it. Without a passkey saved, signing in says "No passkeys found". Passkeys made here only work on this page.

Card, with dropdowns not filled

Click Card number and pick a card: the name, number, expiry dropdowns, card type and brand fill. The security code (CVC) is kept only if you saved it. Press Pay to be offered to save a new card (never its CVC).

Card, no hints not filled

The same without autocomplete hints: Jace Passwords has to recognize the fields by their names, and a single MM / YY box.

Card in a frame frame

Many checkouts put card fields in a frame from their payment provider. This frame is from this site: pick a card in it, or in the Name field above it, and the frame's fields fill too.

Address not filled

Click any field and pick an identity: everything fills, including the state and country dropdowns. Press Save address to be offered to save a new one.

Contact details not filled

A newsletter-style form: full name, email, phone and birthday, recognized by their labels.

Report a field not filled

These boxes have meaningless names, so autofill can't tell what they are. Right-click one → "What is this field?" and pick what it is (Email or username, Password); it's recognized from then on. Your reports only change this page for you until a second person agrees.
